Usage: rebar verify-opcert [--require-environment <env_id>] [--since <ref>] [--format {text,json}] [--root <path>]

Verify the required-environment operation certificate of the store's closed tickets, which is the op-cert merge-gate. It walks the merged log, groups events by ticket, and for each in-scope closed ticket verifies that verify.require_environment (or --require-environment) produced a valid completion-verifier op-cert signed by a key that this environment's verify.trusted_opcert_keys list names for that environment. It is advisory unless a required environment is set, in which case any enforced closed ticket without a valid cert fails the gate with a non-zero exit. A required environment without a trust list is a configuration error. Tickets whose close commit predates --since or verify.opcert_enforce_since are grandfathered, which means reported but never fail the gate. Those verify settings and tracker.dir come from the project config committed on the reviewed base, never from the checkout under review, so a change cannot widen its own gate. The base is the environment's sync.remote (default origin) at that remote's default branch (<remote>/HEAD), else <remote>/main, then one hop to a <remote>/<branch> that the base's own [snapshot].ref names. REBAR_GATE_REF and the checkout's [snapshot].ref are ignored. A checkout with a remote but no resolvable base is a configuration error. A checkout with no remote reads its working tree.

options:
  -h, --help            show this help message and exit
  --require-environment ENV_ID
                        environment that must sign (default:
                        verify.require_environment)
  --since SINCE         grandfather boundary. Only enforce tickets closed at or
                        descending this ref (default:
                        verify.opcert_enforce_since)
  --format {text,json}  output format (default: text). json prints only a report
                        array to stdout
  --root ROOT           repo root that resolves the ticket store (default: cwd)
